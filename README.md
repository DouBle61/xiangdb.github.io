> 📱 高级、极简、极致留白，Apple 官网页面体验。  
> ✨ 完全响应式 | 多身份主页 | 防下载防护 | 手动数据维护 | 极简 Footer

---

## 项目简介

本项目是 DouBle 的个人品牌主页，采用 Apple 官网页面结构和交互风格，支持 4 种身份及生活频道，内置严格防下载防护，完全响应式，所有内容只依赖静态 HTML + Tailwind CDN + Vanilla JS。**无需任何服务端或构建工具，直接部署 GitHub Pages 即可！**

---

## 目录结构

```
/
├── index.html                 # 主页面骨架，只负责调用各模块
└── assets/
    ├── css/
    │   └── style.css          # 样式文件（微交互、阴影、响应式等）
    ├── js/
    │   ├── tailwind.config.js # Tailwind 自定义配置
    │   ├── data.js            # 全站文字、图片路径，主要内容维护这里
    │   ├── utils.js           # 工具函数（图片防护、微交互等）
    │   ├── pages.js           # 所有页面渲染与逻辑
    │   └── app.js             # 启动与全局事件绑定
    └── img/
        ├── avatar.jpg         # 主头像
        ├── avatar-life.jpg    # 生活频道头像
        ├── home-design.jpg    # 主页四身份封面图
        ├── home-direct.jpg
        ├── home-scholar.jpg
        ├── home-charity.jpg
        ├── home-life.jpg      # 中央圆生活照
        ├── design/            # 设计作品图片组
        ├── direct/            # 编导作品图片/视频
        ├── scholar/           # 学者作品图片
        ├── charity/           # 公益作品图片
        └── life/              # 生活照（6张*多组）
```

## 快速启动

1. **克隆仓库或上传文件至 GitHub，新建名为 `[你的用户名].github.io` 的仓库即可部署 GitHub Pages。**
2. 修改 `assets/js/data.js` 内的内容（所有文本与图片路径都集中管理）：
   - 主页头像、背景图片路径
   - 各身份介绍与作品内容
   - 联系方式图标链接、生活频道描述等
3. 上传你的图片到对应文件夹（`assets/img/` 下分组见上）
4. 访问 `https://[你的用户名].github.io` 即可上线！

> ⚠️ GitHub Pages 部署后图片未显示，检查路径和文件名大小写是否完全一致。

## 功能与交互说明

- 💎 Apple 风格极简设计，大圆角、大量留白、柔和阴影
- 🧑‍💻 主页：30:70 左右分栏，中央圆形生活频道（纯图片）
- 💬 二级页面：身份专属简介，作品分页展示，所有内容区块绝对等高
- 🖼 三级详情：设计为图片轮播，编导为视频/活动，学者为滚动论文，公益为小红书图文混排
- 🏞 生活页：一段统一描述文字 + 6宫格朋友圈照片墙，「换一换」随机切换全部内容，有淡入淡出动画
- 📱 响应式：移动端上名片横向铺满且无多余空白，上下堆叠
- 🚫 图片/视频防下载：多重 JS & CSS
- 🔗 社交图标：邮箱、微信、小红书、GitHub、Reddit
- ⌨️ 快捷键支持：ESC 返回，左右箭头切换轮播

## 如何维护内容

- 所有文字、图片、作品数据集中在 `assets/js/data.js`
- 修改数据无须编辑页面 JS 或 HTML骨架，仅需改 data.js
- 上传新图片至 `assets/img/` 下对应分组并保持文件名一致
- 新增/修改作品、身份、生活频道内容直接添加/修改 data.js 即可

---

## 自定义/扩展建议

- 新增身份频道：复制 data.js 内 profiles 模板，主页卡片添加
- 新增作品类别、生活频道组：扩展对应数组即可
- 替换/扩展 SVG icon：交换 `index.html` 内的 icon 部分 SVG 即可
